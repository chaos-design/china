造纸术

The Art of Papermaking
摘 要造纸术为中国古代书写材料之重大变革。本节考其源流，自西汉麻纤维纸之滥觞，至东汉蔡伦之系统改良，论述其原料、工艺与传播路径，并析其于世界文明知识传播中之深远影响。
关键词：造纸术；蔡侯纸；植物纤维；技术西传

历史来源

1.1 起源考

纸之雏形可溯至西汉，早期已见以麻类纤维制成之灞桥纸1957年于西安灞桥出土的西汉麻纸残片，是较早发现的植物纤维纸实物，证明造纸技术在蔡伦之前已有萌芽。[1]。东汉元兴元年（公元105年），蔡伦东汉宦官，总结改良前人经验，以树皮、麻头、破布、旧渔网制纸，史称“蔡侯纸”。总结前人经验，以树皮、麻头、破布、旧渔网为料，系统改良工艺[2]，使纸张得以大规模、低成本生产，遂取代笨重之竹简与昂贵之缣帛。

发展沿革

2.1 历代演进与外传

魏晋南北朝时染色纸、涂布纸渐兴；隋唐之际纸广用于书画印刷，宣纸渐负盛名；宋元竹纸普及，产量大增。公元八世纪，造纸术经怛罗斯之战公元751年唐与阿拉伯的战役，被俘唐军工匠将造纸术传入撒马尔罕，进而经阿拉伯传播至欧洲。西传[3]，再由阿拉伯入欧，深刻推动世界知识之传播。

古法制造工序

  1. 斩竹漂塘：砍取嫩竹，浸泡池塘百日以上软化纤维。
  2. 煮楻足火：拌入石灰入楻桶蒸煮，去除木质素杂质。
  3. 舂捣打浆：反复舂捣煮烂竹麻成均匀纸浆。
  4. 荡料入帘：纸浆兑水，以竹帘细竹丝编成的捞纸工具，是手工抄纸核心，决定纸张厚薄与帘纹。荡捞使纤维均匀附着。
  5. 覆帘压纸：湿纸层层叠压，压榨脱水。
  6. 透火焙干：贴于火墙烘干，揭下即成纸。

  • 手工到连续：逐张抄捞 → 自动化纸机流水线。
  • 经验到可控：工匠经验 → 精确参数与在线检测。

印刷术

The Art of Printing
摘 要印刷术发轫于隋唐雕版，成熟于宋代活字。本节梳理由雕版至活字之技术跃迁，考毕昇胶泥活字之首创及材料演进，并论其西传与欧洲金属活字革命之渊源关系。
关键词：雕版印刷；活字；毕昇；技术传播

历史来源

1.1 雕版与活字之肇始

印刷术起源于隋唐之际之雕版印刷在整块木板上雕刻凸起反字，刷墨覆纸刷印；现存最早有明确纪年的雕版印刷品为唐代《金刚经》（公元868年）。[1]。北宋庆历年间（约1041—1048年），平民毕昇北宋布衣，发明胶泥活字印刷术，事迹见于沈括《梦溪笔谈》。发明胶泥活字印刷术，开“活字”排版之先河[2]。

发展沿革

2.1 材料演进与西传

雕版印刷于唐宋间高度成熟，催生大量典籍与纸币交子北宋四川出现的世界最早纸币，其印制依赖成熟的雕版印刷技术。。活字材料历经胶泥、木、锡而至铜；元代王祯创转轮排字盘。技术西传后，影响十五世纪欧洲古登堡15世纪德国人，发明铅合金活字与螺旋压力印刷机，推动欧洲印刷革命。之金属活字革命[3]。

古法制造工序（活字）

  1. 制字坯：以胶泥刻出单字，字体凸起，每字一印。
  2. 烧制活字：泥字以火烧硬，坚固耐用。
  3. 设板药剂：铁板铺松脂、蜡和纸灰的黏合剂。
  4. 排版固字：排列活字后加热熔药，压平冷却固定。
  5. 刷墨印刷：字面刷墨，覆纸刷印得印张。
  6. 拆版重排：加热熔药取下活字，归类重用。

演变时间线与规律

隋唐·868年
雕版成熟：《金刚经》最早纪年印品。
北宋·约1045年
活字首创：毕昇发明胶泥活字。
元代
器具改良：王祯木活字与转轮排字盘。
明清
套色繁荣：铜活字、饾版拱花。
15世纪·欧洲
西传革命：古登堡铅合金活字。
近现代

演变规律
  • 整→散→数字：整版雕刻 → 活字 → 数字字库。
  • 材料升级：泥木 → 金属 → 数字字体。
  • 单色到全息：单色 → 套印 → 高保真数码。

火药

Gunpowder
摘 要火药源出唐代炼丹，初为方士偶得，继而用于军事。本节考其炼丹起源、宋代火器之勃兴及配方之载录，并论其经蒙古西征传入欧洲、深刻重塑世界战争形态之历史意义。
关键词：火药；炼丹术；硝石；管形火器

历史来源

1.1 炼丹偶得

火药源于古代炼丹术方士追求长生所进行的化学实验，炼丹中意外发现硫磺、硝石与炭混合燃烧爆炸的特性，孕育了火药。[1]。唐代炼丹家配制丹药时，察硫磺、硝石、木炭混合可剧烈燃烧，火药雏形由是诞生，唐末已用于军事。

发展沿革

2.1 火器勃兴与西传

宋代火药武器迅速发展，突火枪南宋以竹筒为枪管、内装火药与“子窠”的管形火器，被视为现代枪炮雏形。、火箭、震天雷相继而出；《武经总要》首载完整配方[2]。元明金属管形火器趋于成熟。火药经蒙古西征与阿拉伯传入欧洲[3]，彻底改变世界战争形态。

古法制造工序

  1. 提纯硝石：溶解、过滤、结晶硝石主要成分硝酸钾，作为氧化剂提供燃烧所需氧气，是火药威力关键。去除杂质。
  2. 炼制硫磺：熔化提纯硫磺，去除砂石。
  3. 烧制木炭：柳木、桐木隔绝空气烧成松软木炭。
  4. 按比配料：按约硝75%、硫10%、炭15%称量。
  5. 研磨混合：分别研末后充分混匀。
  6. 造粒晾干：加水造粒阴干防潮，提升稳定性。

  • 性能跃升：低爆速黑火药 → 高能无烟炸药。

指南针

The Compass
摘 要指南针肇始于战国司南，成熟于宋代磁针。本节考其由天然磁石指极至人工磁化之技术演进，析沈括所记磁偏角之科学价值，并论其用于航海、经阿拉伯传入欧洲、开启大航海时代之意义。
关键词：司南；人工磁化；磁偏角；罗盘航海

历史来源

1.1 司南之制

指南针之前身为战国时期之司南用天然磁石琢磨成勺形，置于光滑铜盘上静止后勺柄指南，是利用磁石指极性的最早装置。[1]。其利用天然磁石之指极性以辨方向，乃人类利用地磁之早期实践。

发展沿革

2.1 磁针成熟与航海应用

宋代实现重大突破：人工磁化用天然磁石摩擦钢针使其获得磁性，使指向工具摆脱天然磁石形状限制，更轻便灵敏。钢针技术成熟，沈括《梦溪笔谈》记缕悬法等装置，并发现磁偏角磁针所指方向与真正地理南北之间的夹角，沈括是世界上较早记录这一现象的人。[2]。水浮磁针与方位盘合为罗盘，广用于航海，并经阿拉伯传入欧洲[3]，开启大航海时代。

古法制造工序（水浮针）

  1. 选取钢针：挑选细直钢针作指向体。
  2. 磁石磨针：用天然磁石沿同一方向反复摩擦磁化。
  3. 检验磁性：测试能否吸附铁屑确认磁化。
  4. 制作浮漂：磁针穿过灯芯草或托于薄木片漂浮。
  5. 水浮定向：置于盛水碗中，旋转静止后指向南北。
  6. 配方位盘：结合二十四方位罗盘读取精确方向。
