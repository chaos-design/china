plan# 重构 /china/qing-officials 官职制度视图：单屏沉浸 + 折叠立体树 + 左右包围

## Context

用户对「官职制度」（图一 3D 立体树）视图提出四点重构要求（已确认方案）：
1. **整页单屏沉浸**：朝代选择、视图切换现在各占一整行，把画布下推；改为一条紧凑顶条，主要内容撑满可视区（仿 `/china/ranks`，页面不滚）。
2. **视角控件并入左侧菜单**：斜视/正视/重置视角从顶中悬浮移入左菜单（对齐 ranks「对照 · 视图」模式）。
3. **立体树默认折叠到分区 + 节点直接展开/折叠**：现在 96 节点全铺开、标签互相覆盖；默认只显示 皇帝 + 4 荣衔组 + 6 分区（11 节点），点节点直接展开/折叠属官，左菜单加「展开全部 / 收起全部」。
4. **左右包围 + 品级跨度（两者都要）**：左侧常驻菜单（从属入口 + 每区品级跨度，如「中枢部 · 正一品—正五品」）+ 右侧详情抽屉包夹画布；同时 3D 场景内给每个分区子树画包围框并标注品级跨度。

## 实现方案

### 1. 页面骨架（`qing-officials-page.tsx`）

- `<article>` 改 `flex h-full flex-col overflow-hidden`（`<main>` 是 min-h-0 flex-1 的定高容器，`h-full` 可解析，ranks 已验证），去掉 `max-w-6xl` 纵向堆叠。
- **紧凑顶条**：`h1 官制图谱（text-2xl/3xl） + 朝代 fieldset（紧凑 chips，px-2.5 py-1 text-sm） + 图谱视图 tablist` 同一行 flex-wrap；下一行小字（text-xs muted，line-clamp-1）合并 `period/system/source + 「{name} · {active.note}」`；未知朝代 notice 保留（aria-live 小行）。
- tabpanel 区 `flex-1 min-h-0`：
  - 官职制度 → `QingOfficeTree` 撑满（stage `h-full`）；
  - 品级礼制 → `h-full overflow-y-auto` 内部滚动列（poster 组件不动，footnote 放列尾）。
- route-layout-config 不变（默认布局即可）。

### 2. 折叠/展开数据层（`office-tree-layout.ts` + 测试）

- 新增纯函数 **`clipAtlasToVisible(atlas, expanded: ReadonlySet<string>)`**：折叠节点的 children 被剪掉（荣衔组 children / 分区 nodes 递归过滤），返回可直接喂 `layoutOfficeTree` 的 atlas；`expanded = {}` 时恰好 11 节点（root + depth-1）。
- 新增纯函数 **品级跨度解析**：regex `(正|从)?[一二三四五六七八九]品` 提取各节点 rank 字符串中的品级（处理「尚书 从一品 · 侍郎 正二品」「正三品至正六品」「正一品封号」「未入流」「加衔无定品」等实际写法），按 subtree 汇总成 min—max 跨度文本；无命中 → 「无定品」。输出 `branchRankSpans(atlas)`：6 分区 + 荣衔簇（正一品—正二品）。
- 两者都加单测（`office-tree-layout.test.ts`）：11 节点默认剪裁、展开后全量、跨度解析覆盖 qing 全部实际 rank 写法。

### 3. 舞台组件（`qing-office-tree.tsx`）

- figure 改 `h-full w-full`（去掉 560/680/760 固定高）。
- **展开状态**：`expanded: ReadonlySet<string>`（默认空集），`clippedLayout = layoutOfficeTree(clipAtlasToVisible(atlas, expanded))` 经 `useMemo` 传给 `useOfficeTreeScene` —— 复用现有 `setAtlas` 同步 effect，展开/折叠 = 场景重建 + 自动重新取景（与切朝代同路径、同成本）。切朝代重置 expanded。
- **onPick 语义**：点带属官的节点 = 直接展开/折叠（toggle expanded）+ 打开详情抽屉（现行为保留）；叶子节点 = 仅详情。全量 layout 的 children 判断可展开性。
- **左侧合并菜单**（替换现 `RelationFilterPanel` + 顶部 `ViewControls`，仍 `absolute left-3 top-3`、可收起、max-h 钳高 + 内部滚动）：
  - 从属入口 chips：全景 / 皇帝 / 荣衔封号（+跨度）/ 6 分区（每枚带 `mark + title + 品级跨度` 小字，跨度来自 `branchRankSpans`）——点击行为不变（高亮 + 抽屉）；
  - 树展开组：「展开全部 / 收起全部」两枚按钮；
  - 视角组：斜视 / 正视 / 重置视角（沿用 `scene.applyPreset / resetView`）。
- canvas `aria-label` 改为「可见 N 节点 · 共 96 节点」口径；hover 读出对可展开节点追加「点击展开/折叠」提示。
- 右侧抽屉、底部 hover 读出、左下 hierarchyNote 均保留；画布让位抽屉的 `lg:right-[360px]` 逻辑保留。
- 2D 降级镜像不变（完整内容 + 已有逐节点展开）。

### 4. 3D 场景（`office-tree-scene.ts`）——分区包围框

- `rebuild()` 内按 分区/荣衔簇 计算可见子树的包围盒（节点 x/y/z + 标签余量），画一个扁平矩形框（`LineSegments`，ochre 半透明，z 置于节点后方）+ 框顶一枚小号标签 sprite（品级跨度文本，复用 `createLabelSprite`）。
- 可见节点 < 2 的（分区折叠后只剩分区节点）不画框，避免六个小空框；框不可拾取（不进 pickMeshes）、随 `content` 组一起 dispose；themeObserver 联动重着色（纳入现有 mesh 重着色循环或存 material 数组）。
- 标签防重叠调优：`slotGap 0.6 → 0.8`、office 标签 20→17px、荣衔子标签 15px（展开全部时缓解拥挤；展开/折叠 + 包围框本身已大幅减少同屏标签数）。改完在真实浏览器过一遍并微调一次。

### 5. 测试（`qing-officials-page.test.tsx`）

- 现有断言迁移：斜视/正视/重置视角、从属筛选 chips、抽屉、setAtlas 计数等仍按 role/name 查找（位置变化不影响）。
- 新增：默认折叠（首次 `setAtlas` 的 layout.nodes.length === 11）；3D 路径 `onPick {id:"six-boards"}` 后 `setAtlas` 收到 17 节点布局（展开）；「展开全部」→ 96 /「收起全部」→ 11；左菜单分区 chip 含品级跨度文本（如 中枢部 chip 内含「正一品」）；品级礼制视图断言不变（内部滚动不影响 DOM）。
