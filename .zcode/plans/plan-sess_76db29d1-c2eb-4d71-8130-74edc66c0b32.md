# 重构 /china/ranks 立体品级树为 timeline 式全屏舞台布局

## Context

用户要求参考 `/china/timeline` 重构页面布局，让重点落在中间区域的 3D 可视化上。选定目标：**`/china/ranks`（品级纵横）**（分支最新提交的立体品级树所在页面；`/china/officials` 已是全屏舞台模式，无需改动）。

现状问题：树画布被钳制在 `h-[clamp(420px,62vh,640px)]`，上方压着三行控件卡（~150px），下方跟着状态条 + 品级·职权网格——可视化被上下内容夹住，首屏约一半被文字/控件占据。

目标（timeline 的布局范式）：桌面端首屏 = 满幅舞台，画布 `absolute inset-0` 铺满 header 以下整屏，所有 UI 变成贴边悬浮层，中间是纯 3D 树；其余四个 section（族谱/阶梯/追踪/断面）保留，向下滚动可见。移动端（<lg）维持现有堆叠流式布局。采用 `lg:` 前缀单画布 host 双模式，与 `officials-hall-page.tsx` 的做法一致。

## 改动文件

### 1. `src/pages/ancient/china-ranks/ranks-page.tsx`

- `<article>` 改为 `flex flex-col lg:h-full`（main 是 definite-height flex item，百分比链成立，同 officials/atlas 先例）。
- header、下方 sections 容器加 `lg:shrink-0`（防止 flex 在固定高度下压缩内容而不溢出滚动）。
- header 保留 h1 + 徽章（瘦身），intro 段落 + 「进入品秩全景」链接移到下方 sections 容器顶部作为「先看树、再看族谱…」的过渡块；树的「读图口径」脚注也从 tree section 移入此块。

### 2. `src/pages/ancient/china-ranks/rank-tree-section.tsx`（主体重构）

section 根：`relative flex flex-col gap-5 lg:min-h-0 lg:flex-1 lg:gap-0`（flex-1 填满 header 以下的整个首屏）。

DOM 顺序（同时服务两种模式）：**左悬浮面板 → 画布盒 → WebGL 降级 → 底部悬浮块 → 右悬浮面板**。

- **画布盒**：外层 `relative overflow-hidden rounded-xl border … lg:absolute lg:inset-0 lg:z-0 lg:rounded-none lg:border-0`；内部唯一 host 保持 `role="img"` + 原 aria-label，`h-[clamp(420px,62vh,640px)] lg:h-full`。`rank-tree-scene.ts` 用 ResizeObserver + getBoundingClientRect 尺寸，**零改动**。
- **左悬浮面板**（标题 + 全部控件，参考 officials 左面板）：移动端是流式卡（≈现状）；`lg:absolute lg:top-5 lg:left-5 lg:z-20 lg:w-[280px] lg:max-h-[calc(100%-2.5rem)] lg:overflow-y-auto` 玻璃卡（border + bg-paper/85 + backdrop-blur-xl）。内容：eyebrow + h2「一树看尽…」+ 描述 → 树·朝代 chips + 级/官计数 → 双朝并置 toggle + 对比 chips → 层高/分列/视角/自动旋转/重置 → footer：文官/武官/双枝 legend + 品序轴/分列 meta + 聚焦徽章。
- **底部悬浮块**（hover 读出 + 品级 chips）：移动端流式；`lg:absolute lg:inset-x-0 lg:bottom-4 lg:z-10 lg:flex lg:flex-col lg:items-center`，容器 `lg:pointer-events-none`，品级 chips fieldset 恢复 `pointer-events-auto`（键盘可达性不变）。hover 读出 `line-clamp-2` 居中。
- **右悬浮面板**（本级职权 + 详情，timeline #panel 对应物）：移动端流式网格（≈现状）；`lg:absolute lg:right-5 lg:inset-y-5 lg:z-20 lg:w-[min(30vw,380px)] lg:overflow-y-auto` 玻璃卡。内容：品级·职权 header + TierColumn（对比模式两列纵排）+ OfficeDetailCard，**常驻显示**（不引入开关状态，交互逻辑零改动）。
- 所有 aria-label 原样保留：立体品级树 / 树状朝代选择 / 树状对比模式 / 秦本级职权 / 树状品级选择 / 品级树详情；fieldset 语义、字号刻度（0.7rem meta）不变；compare 禁用主朝代、`nextDynastyId` 回退等逻辑不动。

### 3. `src/pages/ancient/china-ranks/rank-tree-section.test.tsx`

- 新增一条结构断言：画布盒在 lg 下为 `lg:absolute lg:inset-0`、左右面板悬浮类存在（视觉类改动的 focused DOM/class assertion）。
